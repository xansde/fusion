ABCCard — the four foundation cards at the top of the plan column: Ancestralidade, Herança, Antecedente, Classe. Green check + uppercase type-label + chosen name.

```jsx
<ABCCard typeLabel="Ancestralidade" name="Ratfolk" />
<ABCCard typeLabel="Classe" name="Magus" subLine="Estudo Híbrido: Starlit Span" />
```

Set `done={false}` for an unfilled foundation (dashed empty circle). Stack them with an 6px gap above the level cards.
