# @fusion/importer-pf2e

CLI pipeline that extracts PF2e compendium data from the `vendor/pf2e` clone and
transforms it into Fusion packs (ORC-licensed data only; all Paizo art and lore
replaced by placeholders).

## Pipeline stages

| Stage         | Script                     | Output                                                    |
| ------------- | -------------------------- | --------------------------------------------------------- |
| 1. Extract    | `src/extract.mjs`          | `out/<pack>/extracted.json`                               |
| 2. Normalize  | `src/normalize.mjs`        | `out/<pack>/normalized.json`                              |
| 3. Transform  | `src/transform.mjs`        | `out/<pack>/transformed.json`, `out/fusion-uuid-map.json` |
| 4. MVP subset | `src/build-mvp-subset.mjs` | `systems/pf2e/packs/<slug>/`                              |

## Prerequisites

1. **Clone the pf2e system** into `vendor/pf2e` (gitignored; Paizo art/proprietary data):

   ```
   git clone --depth 1 https://github.com/foundryvtt/pf2e vendor/pf2e
   ```

2. **Run all stages in order**:
   ```
   node src/extract.mjs --packs equipment,spells,conditions,pathfinder-monster-core
   node src/normalize.mjs --packs equipment,spells,conditions,pathfinder-monster-core
   node src/transform.mjs --packs equipment,spells,conditions,pathfinder-monster-core
   node src/build-mvp-subset.mjs
   ```

## Running the transform tests

The test file `src/__tests__/transform.test.mjs` validates the transform output
against the contents of `out/<pack>/transformed.json` (generated by stage 3) and
`systems/pf2e/packs/<slug>/` (generated by stage 4).

**These files are gitignored and must be generated locally before running tests.**

```
# 1. Generate all required files (see Prerequisites above)
# 2. Run the tests:
node --test src/__tests__/transform.test.mjs
```

In CI without the vendor clone the tests will fail because `out/` is not present.
The `systems/pf2e/packs/` committed subset can be validated independently; the
structural and art-policy checks against the MVP packs (test group "MVP packs")
only require `systems/pf2e/packs/` and run without `out/`.

A minimal synthetic fixture (`samples/<pack>/sample-*.json`) is provided for
reference and manual inspection but is not wired to the pnpm test pipeline.

## Legal

- Only ORC-licensed mechanical data is included in the committed `systems/pf2e/packs/`.
- Paizo art (`systems/pf2e/icons/`) is replaced by placeholders (`icons/placeholder/`).
- NPC lore/flavor text (`publicNotes`, `blurb`) is stripped — Reserved Material under
  ORC (spec 26 §D4, REQ-LEG-010).
- The `vendor/pf2e` clone is gitignored and must not be committed.
