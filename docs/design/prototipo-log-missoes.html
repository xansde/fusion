Isekai · Yennericka — Hub do jogador (spec 28)

Log de Missões — o board de quests do Hub

Protótipo de tela para o Hub do jogador: o board onde Tobias e Comedor acompanham o que já foi publicado, o que ainda é só boato e o que já foi encerrado. A aba Mestre mostra a matriz de publicação por trás — cada botão aqui é, na implementação real, um update de ownership, nunca um sistema paralelo de "missões". A barra de comando embaixo abre também a Comitiva (referência rápida dos PCs) e o Mapa de região — as três janelas seguem o mesmo toggle de papel, no topo.

Como isso vira código de verdade

Nada aqui é UI inventada: cada peça do protótipo corresponde a um documento do Fusion que já existe ou já está especificado.
