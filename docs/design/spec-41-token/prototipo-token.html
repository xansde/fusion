Protótipo de Token — spec 41

Não é implementação nem spec: é uma maquete executável das 30 decisões, para ver o que cada uma produz antes de escrever o texto. Tudo que aparece aqui é derivado do modelo decidido — a peça não tem arte, nem tamanho, nem posse próprios. Embaixo, o contrato de expectativas roda sozinho contra o modelo.
