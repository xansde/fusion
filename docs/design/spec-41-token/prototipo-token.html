Protótipo de Token — spec 41

Maquete executável das decisões, para ver o que cada uma produz antes de escrever o texto. Tudo aqui é derivado do modelo decidido — a peça não tem arte, tamanho, posse nem nome visível próprios. Três camadas separadas, e a spec precisa não confundi-las: o que o servidor manda (posse e conhecimento), o que a peça é (posição e vínculo), e o que o usuário escolhe ver. Embaixo, o contrato de expectativas roda sozinho contra o modelo.

Quem está olhando

A cena é redigida no servidor, por socket. Trocar aqui recalcula o que aquele cliente receberia. D21 · D31

Preferências deste usuário cliente

Escolha de quem joga, e só tira da tela o que ele já podia ver. Desligar não muda uma vírgula do payload — confira no inspetor à direita. D32

Conhecimento

Nome não é nível de exibição: é conhecimento. Quem não conhece o ator não recebe o nome dele. D31
